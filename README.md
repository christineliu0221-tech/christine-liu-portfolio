# Christine Liu — Market-Facing Portfolio

A public professional portfolio for Yu-Hsuan Christine Liu, U.S. CPA and Wake Forest MSBA candidate. The site presents her audit, risk analytics, and business-impact narrative through selected case studies, current market context, and an integrated resume.

## Local setup

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Portfolio structure

- Executive introduction and video placement
- Targeting Track career narrative
- Audit and analytics expertise
- Three detailed project case studies
- Commercial-awareness research
- Viewable and downloadable PDF resume
- Contact information

The layout is responsive and designed for both laptop and mobile review.
